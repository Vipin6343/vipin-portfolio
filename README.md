# Vipin Yadav - Portfolio

React, Vite, and Tailwind portfolio based on Vipin's resume.

## Run locally

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

Content lives in `src/data.js`; the downloadable resume is `public/Vipin_Yadav_Resume.pdf`.
Project detail routes use `/systems/:slug`. `vercel.json` supplies the SPA fallback.
Set the canonical URL and generate a sitemap after choosing the deployment domain.
